# Kontur

Python-проект для интеграции с Контур ЭДО.

## Быстрый старт

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
python -m pip install -e ".[dev]"
python -m pytest
```

## Конфигурация

Скопируйте `.env.example` в `.env` и заполните значения для доступа к API.
